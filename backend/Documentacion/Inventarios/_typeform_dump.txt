==== Llaves y variantes de input ====
# | Llave / valor | Categoría | Descripción | Detalle
1 | (nombre del campo) | Llave de input | La llave del diccionario fields[fila][campo] es el nombre visible del input: se pasa como prop name y se usa de etiqueta y placeholder. | fields es un dicc {fila: {nombreCampo: infoCampo}}; las filas se ordenan numericamente
2 | ref | Llave de input | Identificador logico del campo: llave con la que el valor se envia al backend (formData.append(ref, value)) y con la que se crea la referencia React para validar/limpiar. | obligatoria; tambien forma parte del id DOM (idForm-fila-ref)
3 | type | Llave de input | Tipo de control a renderizar; selecciona el caso del switch de Input.getTypeInput y las validaciones de validInput/validValue/formatValue. | ver catalogo de types (modulo input)
4 | variant | Llave de input | Variante visual del input (prop variant de Input); define etiqueta, iconos y botones alrededor del control. En el JSON de fields la llave es 'variant'. | valores: Input, InputGroup, InputGroupAlert, InputGroupIcon, InputMenusIcons, InputClassic, InputQuiz (ver modulo variante)
5 | modifier | Llave de input | Diccionario de configuracion especifica del type: opciones, rangos, catalogos, enlaces, callbacks y ajustes de la variante (optional, icon, clearButton, modifyButton, alertmessage, style, localConfig, overrideValue). | llaves segun type: options, contextOptions, contextValue, min, max, contextMin, contextMax, errorMin, errorMax, catalogo, filter, contextFilter, errors, contextDinamicOptions, pickers, numRows, link, linkStr, textHover, accept, url, token, subtitle, changevalue, style, optional, icon, clearButton, modifyButton, alertmessage, localConfig, overrideValue
6 | config | Llave de input | Diccionario de props que se esparcen directamente sobre el control React-Bootstrap (readOnly, disabled, maxLength, onBlur, etc.); el Formulario inyecta config.readOnly=true cuando block/readOnly/blockForm/blockValue lo indican. | config.readOnly, config.disabled, config.onBlur (usado por rfc/curp para consultas encadenadas)
7 | value | Llave de input | Valor inicial del campo; si datosIniciales[ref] existe (datos previos del tramite) tiene prioridad sobre infoCampo.value. Pasa por formatValue del Input segun el type. | modifier.overrideValue lo sobre-escribe (reseteo)
8 | valid | Llave de input | Si es false el campo se excluye de validarForm (no se llama validValue antes de enviar); default true. | booleano
9 | block | Llave de input | Si es true el campo se marca readOnly y ademas limpiarForm no borra su valor. | booleano; tambien blockForm a nivel formulario fuerza readOnly en todos
10 | blockValue | Llave de input | Si es true el campo se vuelve readOnly solo cuando ya trae un valor (inicial o de datosIniciales); permite editar campos vacios y congelar los precargados. | booleano
11 | readOnly | Llave de input | Fuerza el modo solo lectura del campo (equivalente a block en el calculo de config.readOnly, pero sin excluirlo de limpiarForm). | booleano
12 | errormessage | Llave de input | Mensaje de error por defecto del campo (prop error del Input); si no se define se usa 'Valor invalido.'. Algunos types lo sustituyen por mensajes propios (RFC, CURP, telefono, min/max). | string
13 | key | Llave de input | En FormularioDinamico y FormularioFiltro: sufijo/indice usado para generar ids y refs unicos cuando el campo se repite dinamicamente. | usado como parte de refs[key+ref]
14 | dynamic / form | Llave de input | En FormularioDinamico: dynamic marca el campo como generado dinamicamente y form indica el sub-formulario al que pertenece. | solo formulario_dinamico
15 | filter / query / filterFormsId / filterFieldsId / valueBlock / deleteData | Llave de input | En FormularioFiltro: llaves para encadenar filtros entre formularios (query con placeholders, ids de formularios/campos fuente, bloqueo por valor y exclusion del payload). | solo formulario_filtro
16 | Input | Variante visual | Variante minima: renderiza solo el control, sin etiqueta, icono ni contenedor. | ninguna llave de modifier aplica
17 | InputGroup | Variante visual | Etiqueta 'nombre:' a la izquierda del control dentro de un InputGroup horizontal; soporta boton de limpiar y boton candado para alternar readOnly. | modifier.optional (tooltip 'Campo Opcional' y estilo), modifier.clearButton (boton basura que llama cleanData), modifier.modifyButton (boton candado que alterna readOnly), modifier.style (paleta, default HIR)
18 | InputGroupAlert | Variante visual | Como InputGroup pero antepone un icono de advertencia con popover 'Advertencia' cuyo cuerpo es modifier.alertmessage. | modifier.alertmessage, modifier.optional, modifier.clearButton, modifier.modifyButton, modifier.style
19 | InputGroupIcon | Variante visual | Etiqueta en renglon superior y debajo el control precedido de un icono Bootstrap Icons (modifier.icon). | modifier.icon (clase bi), modifier.optional, modifier.clearButton, modifier.modifyButton, modifier.style
20 | InputMenusIcons | Variante visual | Igual que InputGroupIcon pero con estilos compactos para menus (labelGroupIconMenu / iconInputGroupMenu). | modifier.icon, modifier.optional, modifier.clearButton, modifier.modifyButton, modifier.style
21 | InputClassic | Variante visual | Etiqueta Form.Label arriba del control (layout clasico vertical) con icono opcional a la izquierda; es tambien el render del caso default cuando variant no coincide. | modifier.icon, modifier.optional, modifier.clearButton, modifier.modifyButton, modifier.style
22 | InputQuiz | Variante visual | Variante para cuestionarios: la etiqueta usa estilo labelQuiz (texto de pregunta, sin dos puntos) junto al control. | modifier.optional, modifier.clearButton, modifier.modifyButton, modifier.style
23 | (default de variant) | Variante visual | Cualquier valor de variant no reconocido renderiza el mismo layout que InputClassic (label arriba + InputGroup con icono opcional). | modifier.icon, modifier.optional, modifier.clearButton, modifier.modifyButton
24 | Row / Column / row2 / row3 / row4 / row5 | Variante visual | NO son variantes del input sino del formulario (prop variant de Formulario.js): Row/Column definen la direccion del contenedor de cada fila; row2/row4 dan doble ancho al primer/segundo campo en filas de 2; row3/row5 igual pero solo en filas cuyo id no empieza con 0. | se declara a nivel formulario, no en el campo
